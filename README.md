# FastCopy

在**手机和电脑之间**快速传输复制的文字和文件。

电脑上运行一个小服务，手机扫码就能用浏览器打开，**无需安装 App、无需登录、不经过云端**，数据只在你的局域网内传输。

## 功能

- 📋 **剪贴板同步**：电脑上 `Ctrl+C`，手机上点一下（或敲两下手机背面）就能粘贴；手机发来的文字自动进入电脑剪贴板，直接 `Ctrl+V`
- 📝 **文字互传**：一端发送，另一端实时出现，一键复制
- 📎 **文件互传**：选择文件 / 拖拽 / 直接 `Ctrl+V` 粘贴截图，带上传进度，图片显示缩略图
- ⚡ **实时同步**：基于 Server-Sent Events，所有已打开页面即时更新
- 🔒 **访问令牌**：每次启动生成随机令牌（包含在二维码中），同一局域网里的其他人无法访问
- 🌗 支持深色模式，适配手机屏幕

## 快速开始

需要 Node.js 18 或更高版本。

```bash
git clone https://github.com/yalosaws/fastcopy.git
cd fastcopy
npm install
npm start
```

终端会打印访问地址和二维码：

1. 确保手机和电脑连接**同一个 Wi-Fi**
2. 手机扫描终端里的二维码
3. 电脑浏览器打开终端里显示的同一地址

## 手机 App：完全自动同步

不想每次点一下？安装手机 App（源码在 [`app/`](app/)，Flutter 编写），打开后扫描电脑终端里的二维码即可。

| | 电脑复制 → 手机粘贴 | 手机复制 → 电脑粘贴 |
| --- | --- | --- |
| **安卓** | ✅ 全自动，App 在后台也能同步 | 默认：打开 App / 点通知栏按钮 / 下拉快捷开关「发送剪贴板」；完成一次 adb 授权后 ✅ 全自动 |
| **iPhone** | 打开 App 时自动同步 | 打开 App 时自动同步 |

> iOS 不允许任何 App 在后台读写剪贴板，所以 iPhone 只能在打开 App 时同步（无需再点按钮）。

### 下载安装

每次推送代码后，GitHub Actions 会自动打包：进入仓库的 **Actions → App → 最新一次运行**，在页面底部 Artifacts 下载。

- **安卓**：下载 `FastCopy-android`，解压得到 `FastCopy.apk`，传到手机安装（需允许「安装未知来源应用」）。
- **iPhone**：下载 `FastCopy-ios-unsigned`，用 [Sideloadly](https://sideloadly.io/) 或 AltStore 以你的 Apple ID 签名安装。免费 Apple ID 签名 7 天有效，需定期重新签名；付费开发者账号（99 美元/年）有效期 1 年。

### 安卓设置

1. 打开 App，扫码连接电脑，打开「后台自动同步」
2. 按提示允许**通知**和**不受电池优化限制**（否则可能被系统杀掉；小米 / 华为等还需在系统设置里允许「自启动」「后台运行」）
3. （可选）手机 → 电脑也全自动：
   - 在 App 中点「允许显示在其他应用上层」
   - 手机开启 USB 调试并连上电脑，执行一次：
     ```bash
     adb shell pm grant com.fastcopy.fastcopy android.permission.READ_LOGS
     ```
   - 关闭再打开「后台自动同步」。Android 13 及以上首次会弹出「允许访问所有设备日志」，请选择允许。

   原理：Android 10 起系统禁止后台应用读取剪贴板，但每次拒绝时会写一条系统日志。App 监听到这条日志后，短暂弹出一个透明页面读取剪贴板并发送（与 KDE Connect 相同的做法）。这个模式依赖各厂商系统的实现，部分机型上可能无效。

### iPhone 设置

在「设置 → FastCopy → 从其他 App 粘贴」中选择**允许**，否则每次打开 App 都会弹出粘贴确认。

## 电脑复制 → 手机粘贴（网页版）

服务启动后会自动监听**电脑剪贴板**（Windows / macOS 开箱即用；Linux 需要安装 `xclip` 或 `wl-clipboard`）。

| 方向          | 操作                                                                    |
| ------------- | ----------------------------------------------------------------------- |
| 电脑 → 手机   | 电脑上 `Ctrl+C`，手机页面顶部出现蓝色提示，**点一下即复制**，然后粘贴 |
| 手机 → 电脑   | 在手机页面发送文字，电脑剪贴板自动更新，**直接 `Ctrl+V`**               |

> 为什么手机上还要点一下？手机浏览器出于安全考虑，不允许网页在后台改写剪贴板，必须由一次点击触发。想连页面都不用打开，可以设置下面的快捷指令。

### 免打开页面：手机快捷指令（可选，一次设置）

启动时终端会打印一个「快捷指令地址」，形如 `http://192.168.x.x:8080/api/latest?token=xxxx`，它返回最新一条文字。访问令牌会保存在 `~/.fastcopy/token`，重启后不变，所以快捷指令只需设置一次（建议在路由器里给电脑固定 IP）。

**iPhone（快捷指令 App）**

1. 新建快捷指令，添加「获取 URL 内容」，填入上面的地址
2. 再添加「拷贝到剪贴板」
3. 打开「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下」，选择这个快捷指令

之后：电脑 `Ctrl+C` → 敲两下手机背面 → 直接粘贴。

反方向同理：「获取剪贴板」→「获取 URL 内容」（方法 `POST`，请求体选「文件」并传入剪贴板，地址为 `http://192.168.x.x:8080/api/text?token=xxxx`），手机复制后运行，电脑就能直接 `Ctrl+V`。

**Android**

用 [HTTP Shortcuts](https://http-shortcuts.rmy.ch/) 等应用新建 GET 请求指向同一地址，响应处理选择「复制到剪贴板」，再把它放到桌面或通知栏快捷开关。

## 配置

| 环境变量             | 说明                            | 默认值                                   |
| -------------------- | ------------------------------- | ---------------------------------------- |
| `PORT`               | 监听端口                        | `8080`                                   |
| `FASTCOPY_TOKEN`    | 指定访问令牌                     | 首次随机生成并保存到 `~/.fastcopy/token` |
| `FASTCOPY_CLIPBOARD` | 设为 `0` 关闭电脑剪贴板同步     | 开启                                     |

示例：`PORT=9000 FASTCOPY_TOKEN=mysecret npm start`

## 说明

- 记录保存在内存中，最多保留 200 条；**重启后清空**，上传的文件位于 `uploads/`，也会在启动时清空。
- 单个文件上限 2 GB。
- 剪贴板同步只处理**文字**；在电脑上复制的文件 / 图片请拖进网页发送。
- 由于使用局域网 HTTP，部分浏览器限制剪贴板 API，「复制」按钮会自动降级为兼容方式；如仍失败，可长按文字手动复制。
- 如果手机打不开，请检查电脑防火墙是否放行了对应端口。

## 开发

```bash
npm test                 # 服务端
cd app && flutter test   # 手机 App
```

项目结构：

```
server.js          # HTTP 服务：API、文件存储、SSE 实时推送、剪贴板同步
clipboard.js       # 读写电脑系统剪贴板（Windows / macOS / Linux）
public/index.html  # 前端页面（无构建步骤）
app/               # 手机 App（Flutter；安卓后台同步为原生 Kotlin：app/android/.../SyncService.kt）
test/              # 基于 node:test 的接口测试
```
